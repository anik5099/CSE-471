# Project 4: Simple Calculator

A beginner-friendly Django project that teaches HTML forms and POST request handling without using a database.

## Run

```bash
cd simple_calculator_project
python manage.py runserver
```

Open:

```txt
http://127.0.0.1:8000/
```

## Pages

- `/` - Home page
- `/calculator/` - Calculator form
- `/about/` - Project explanation

## Database

No database is used.
