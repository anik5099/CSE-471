# Project 3: Student List

A beginner-friendly Django project that teaches students how to display multiple records using a list of dictionaries and template loops.

## Run

```bash
cd student_list_project
python manage.py runserver
```

Open:

```txt
http://127.0.0.1:8000/
```

## Pages

- `/` - Home page
- `/students/` - All students
- `/top-students/` - Filtered top students

## Database

No database is used.
