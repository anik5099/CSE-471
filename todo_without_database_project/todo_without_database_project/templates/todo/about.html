About This Project

This is a beginner-friendly Django to-do list project without database.

It teaches:

  • HTML form
  • POST request
  • CSRF token
  • Reading form data using request.POST.get()
  • Using a Python list as temporary storage
  • Redirecting after successful form submission
  • Displaying tasks using a template loop
  • Clearing data from a list

Important: Since this project does not use a database, tasks disappear when the server restarts.
