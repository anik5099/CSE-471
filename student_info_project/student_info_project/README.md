# Project 2: Student Information Display

A beginner-friendly Django project that teaches how to pass data from `views.py` to HTML templates.

## Run the project

```bash
cd student_info_project
python manage.py runserver
```

Open:

```txt
http://127.0.0.1:8000/
```

## Pages

- `/` - Home page
- `/student/` - Student details page
- `/course/` - Course details page

## No database required

This project does not use models, migrations, or database operations.
