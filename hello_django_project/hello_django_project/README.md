# Project 1: Hello Django

This is a very basic Django project for absolute beginners.

## Learning Goals

Students will learn:

1. Django project structure
2. App creation
3. URL routing
4. View functions
5. Template rendering
6. Template inheritance
7. Navigation between pages

## Run the Project

Open terminal inside the project folder and run:

```bash
python manage.py runserver
```

Then visit:

```txt
http://127.0.0.1:8000/
http://127.0.0.1:8000/about/
http://127.0.0.1:8000/contact/
```

## No Database Needed

This project does not use models or database operations.
